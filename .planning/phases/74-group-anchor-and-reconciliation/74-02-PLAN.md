  <action>
Create lib/dal/reimbursement.ts exporting `getReimbursementAggregates(input: { reimbursementId:
number; userId: string }): Promise<{ outflowSum: string; refundSum: string } | undefined>`. Query:
select from `reimbursement r WHERE r.id = ${reimbursementId} AND r.userId = ${userId}` (ownership
scoped in the WHERE clause itself, not a separate check -- IDOR-safe by construction). Compute
`outflowSum` via a CASE: when `r.expenseId IS NOT NULL`, the single Expense's own `totalAmount`
(`SELECT e.totalAmount FROM expense e WHERE e.id = r.expenseId`); else (Group-anchored), the SUM of
`totalAmount` across every member Expense (`SELECT COALESCE(SUM(e2.totalAmount::numeric), 0)::text
FROM expenseGroupMembership egm INNER JOIN expense e2 ON e2.id = egm.expenseId WHERE egm.groupId =
r.expenseGroupId`). Compute `refundSum` via `SELECT COALESCE(SUM(rt.amount::numeric), 0)::text FROM
reimbursementRefund rr INNER JOIN transaction rt ON rt.id = rr.transactionId WHERE
rr.reimbursementId = r.id`. Return undefined when no row matches (missing id OR foreign-owned id --
same generic "not found" shape as updateTransaction's ownership check, no user enumeration).

Create lib/services/reimbursement.ts exporting `computeReimbursementResidual(input: {
reimbursementId: number; userId: string }): Promise<{ residual: string; state: 'owed' | 'settled'
| 'surplus' } | undefined>`. Calls getReimbursementAggregates; returns undefined if it does.
Otherwise: `residual = toDecimal(outflowSum).plus(toDecimal(refundSum))`; `state =
residual.lt(0) ? 'owed' : residual.eq(0) ? 'settled' : 'surplus'`; return `{ residual:
toDbDecimal(residual), state }`. All arithmetic via toDecimal/toDbDecimal -- never native +/-.
