<objective>
Build the shared number engine's foundation — the Covered Month query (D-01/D-04) and the
pace/projection existence threshold (D-05) — end-to-end on real Postgres, and capture the
Overview/Tags byte-identical regression baseline (RETIRE-05, D-15/D-16) before any other Phase 82
code lands.

Purpose: this is the load-bearing correctness rule of the whole v3.0 milestone (ADR 0020 §4) — a
month with no transactions must never inflate a category's average, and a downstream caller must
never be able to mistake "not enough data" for "€0". Both are proven against real seeded data, not
mocked ones.
Output: lib/dal/covered-months.ts, lib/services/pace-and-projection.ts (initial shape), and the
RETIRE-05 regression harness in tests/pace-engine-lens-regression.test.ts.
</objective>
