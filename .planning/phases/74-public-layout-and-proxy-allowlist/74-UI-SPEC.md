## Spacing Scale

Declared values (multiples of 4) — aligned with existing app Tailwind rhythm (`px-4`, `px-6`, `gap-3`, `py-8`, `py-12`):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps inside mobile menu rows |
| sm | 8px | Compact header control gaps (`gap-2`) |
| md | 16px | Default header/footer horizontal padding (`px-4`); link row gaps |
| lg | 24px | Header/footer horizontal padding ≥`sm` (`sm:px-6`); section padding inside stub pages |
| xl | 32px | Footer vertical padding (`py-8`) |
| 2xl | 48px | Stub/placeholder main vertical padding (`py-12`) |
| 3xl | 64px | Optional large stub page top spacing (`pt-16`) if needed for visual balance |

**Exceptions:**

- Mobile menu icon button and primary CTA touch targets: **minimum 44×44px** (may use `h-11 w-11` / `size="lg"` — not a spacing-token multiple for the hit area itself).
- Sticky header height: **56px** (`h-14`) desktop and mobile — fixed chrome band, not a free-form spacing token.

## Typography

Chrome uses Geist only. Exactly four sizes, two weights (400 + 600). No `font-medium` (500) on new public chrome — if an inherited Button size brings medium, leave Button internals alone; do not add medium to custom nav/footer text.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 16px (`text-base`) | 400 | 1.5 | Homepage-shell supporting line; stub page body |
| Label / nav | 14px (`text-sm`) | 400 | 1.5 | Header nav links, footer links, copyright line |
| Heading | 20px (`text-xl`) | 600 | 1.2 | Stub page titles (`Come funziona`, `Privacy`, `Termini`) |
| Display (wordmark) | 24px (`text-2xl`) | 600 | 1.2 | Header + footer “Sparter” wordmark — matches `(auth)/layout.tsx` (`text-2xl font-semibold tracking-tight`) |

**Active nav link:** same size/weight as Label; indicate current route with `text-foreground` + `font-semibold` (600) **or** underline — pick one, do not combine heavy fill + underline. Inactive links: `text-muted-foreground`, hover → `text-foreground`.

## Color

Reuse `app/globals.css` tokens (60/30/10). Approx hex for checker readability; **CSS variables are source of truth**.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--background` ≈ `#ffffff` (light) | Page canvas behind chrome + main |
| Secondary (30%) | `--muted` / `--secondary` ≈ `#f3f4f5`; `--border` ≈ `#e5e7ec` | Sticky header wash (`bg-background/95`), footer top rule, Sheet surface |
| Accent (10%) | `--primary` ≈ `#007f3a` (oklch(0.515 0.154 153.85)) | **Only** primary `Registrati` Button fills + focus rings (`ring`) |
| Destructive | `--destructive` ≈ `#fb2c36` | **Not used in Phase 74** — no destructive actions on public chrome |

**Accent reserved for:** primary CTA Button (`Registrati`) in header, homepage shell, footer (if footer repeats primary CTA as button — prefer text link in footer; see Copywriting), and focus-visible rings on interactive chrome. Never for nav text links, never for large background washes, never purple/glow.

**Foreground:** `--foreground` ≈ `#131825` for wordmark and active links; `--muted-foreground` ≈ `#70737b` for inactive nav/footer links and copyright.

**Dark mode:** ThemeProvider already wraps root — chrome must use semantic tokens only (no hard-coded light hex in components) so dark mode remains coherent. No separate marketing palette.

**Anti-patterns (from Phase 73 D-08 — still in force):** no purple-on-white / purple-indigo gradients, no warm-cream+terracotta serif pairing, no broadsheet hairline layout, no glow, no emoji clusters.

## Layout & Interaction Contract

### Shell structure (BRAND-03)

```
app/(public)/layout.tsx
└── <div class="flex min-h-screen flex-col bg-background">
      ├── SiteHeader (sticky)
      ├── <main class="flex-1">{children}</main>
      └── SiteFooter
    </div>
```

**Forbidden inside `(public)`:** `AppShell`, `SidebarProvider`, app sidebar, `BottomNav`, onboarding gate, `verifySession()` hard-fail, any `(app)` layout import.

**Session in layout:** none in Phase 74. Always show both `Entra` and `Registrati`. Session-aware hide of `Registrati` is Phase 77 (BRAND-12).

### Header — desktop (`md+`)

| Slot | Content | Behavior |
|------|---------|----------|
| Left | Wordmark “Sparter” | Link → `/`; `text-2xl font-semibold tracking-tight text-foreground` |
| Nav | “Come funziona” | Text link → `/how-it-works` |
| Actions | “Entra” | `Button asChild variant="outline" size="sm"` → `/login` |
| Actions | “Registrati” | `Button asChild` (default primary) `size="sm"` → `/register` |

- Sticky: `sticky top-0 z-40 border-b border-border bg-background/95 backdrop-blur supports-[backdrop-filter]:bg-background/80`
- Max content width: full-bleed bar with inner `mx-auto flex h-14 w-full max-w-6xl items-center justify-between gap-4 px-4 sm:px-6`
- **No Pricing link. No Privacy/Termini in desktop header** (footer-only for legal — FEATURES.md).

### Header — mobile (`< md`)

| Slot | Content | Behavior |
|------|---------|----------|
| Left | Wordmark “Sparter” | Link → `/` |
| Right | Primary “Registrati” | `Button size="sm"` → `/register` (always visible — conversion) |
| Right | Menu trigger | Icon button (`Menu`), `aria-label="Apri menu"`, opens shadcn `Sheet` from right |

**Sheet contents (ordered):** Come funziona → Entra → Registrati → separator → Privacy → Termini. Close on navigate. Sheet title visually hidden or “Menu”. Touch rows ≥ 44px tall.

### Footer (every public page)

| Element | Spec |
|---------|------|
| Structure | `border-t border-border`, `py-8`, inner `max-w-6xl mx-auto px-4 sm:px-6` |
| Brand | Wordmark link “Sparter” → `/` (same type treatment as header, or `text-xl`) |
| Nav links (Italian labels → English hrefs) | Come funziona → `/how-it-works`; Privacy → `/privacy`; Termini → `/terms`; Entra → `/login`; Registrati → `/register` |
| Copyright | `© {currentYear} Sparter` — `text-sm text-muted-foreground` |
| Forbidden | Pricing, bank-linking CTAs, app sidebar links, social icon clusters |

Footer links are **text links** (`text-sm text-muted-foreground hover:text-foreground`), not primary Buttons — accent stays reserved for header/shell CTAs.

### Homepage shell `/` (BRAND-05 — Phase 74 only)

Minimal **type-led placeholder** proving chrome + smart root — **not** full Variant C (no product band, no benefit blocks, no Fraunces):

1. Centered column (`max-w-xl mx-auto px-4 py-12 text-center` or similar)
2. Wordmark or short brand line “Sparter”
3. One supporting sentence (Italian, import-first — see Copywriting)
4. CTA group: primary `Registrati` + secondary outline `Entra` (`size="lg"`, `gap-3`)

Authenticated `/` never renders this shell — proxy redirects to `/dashboard` (infra; no UI).

### Stub pages (link-slot destinations)

Until Phase 75/76 fill bodies, allowlisted routes that the chrome links to must render **inside the public layout** (no 404 when clicking footer/nav):

| Route | Stub heading | Stub body |
|-------|--------------|-----------|
| `/how-it-works` | Come funziona | Contenuto in arrivo. |
| `/privacy` | Privacy | Contenuto in arrivo. |
| `/terms` | Termini | Contenuto in arrivo. |

Stub pages: Heading role + Body role only. No fake legal prose (avoids Pitfall: placeholder GDPR claims).

### Route / copy language

- **UI labels:** Italian (`Come funziona`, `Privacy`, `Termini`, `Entra`, `Registrati`)
- **hrefs:** English only (`/`, `/how-it-works`, `/privacy`, `/terms`, `/login`, `/register`)
- Constants live in `lib/routes.ts` (BRAND-04 single source of truth) — chrome imports those constants, does not hard-code divergent paths.

| Category | Element(s) | Status | Resolution / Reason |
