<objective>
Replace the plain "Tutte le transazioni disponibili sono caricate." end-of-list footer message in
`components/transactions/transaction-table.tsx` with a compact, reconciling summary: transaction
count, total in (Entrate), total out (Uscite), and the signed difference (Differenza).

Purpose: give the user a quick sanity-check of the transactions they're looking at, without
implying analytical completeness beyond the current filter/view (that's the dashboard's job).

Output: a small pure helper (`computeTransactionTotals`, grouped per `transaction.currency`) + a
signed-amount formatter (`formatSignedAmount`), wired into the existing footer render, with test
coverage proving the figures reconcile per currency and that partial-scroll states are untouched.
</objective>

**Locked decisions (CONTEXT.md — do not revisit):**

- **D-01** Placement: footer only, replacing the existing "Tutte le transazioni disponibili sono
  caricate." paragraph (`transaction-table.tsx` ~line 967) — not a sticky bar or a card above the
  table.
- **D-02** Totals scope: computed client-side over `loadedTransactions` in the table component. No
  new DAL aggregate/SUM function; no refactor of `getTransactions` (`lib/dal/transactions.ts`).
- **D-03** Partial scroll: while `hasMore === true` (the "Carica altre 50 transazioni" button) or
  `isLoadingMore`, the footer renders exactly what it renders today — no partial totals.
- **D-04** Amount field: per row use `pairedNetAmount ?? amount`. Both are DECIMAL strings — all
  arithmetic through Decimal.js (`toDecimal`), never native `+`/`-`.
- **D-05** In/out split by sign of the net (not the `direction` lookup table, which drops
  uncategorized rows). Entrate = sum of positive nets. Uscite = sum of |negative nets|. Differenza
  = Entrate − Uscite. A net of exactly 0 counts toward the transaction count but neither side.
- **D-06** Scope: transactions table only — do not touch `expense-table.tsx` or
  `import-table.tsx`.
- **D-07** Copy: Italian, compact (label + figures, not a sentence), it-IT EUR formatting
  (existing helpers), Differenza shown signed (`+2.559,50 €` / `-1.204,00 €`).
- **D-08** Multi-currency totals (amendment): `transaction.currency` (`lib/db/schema.ts:432`,
  notNull, default `'EUR'`) is per-row, so totals must group by currency — one bucket per
  currency, never a flat cross-currency sum. Normalize falsy/empty currency to `'EUR'` (mirrors
  `currency || 'EUR'` in `getAmountFormatter`/`formatAbsoluteAmount`). Buckets ordered
  deterministically: count descending, then currency code ascending as a stable tiebreaker. The
  overall transaction count shown to the user stays the total across all buckets
  (currency-independent). Single-bucket case (all-EUR, the normal case) renders identically to the
  pre-amendment plan; multi-bucket case renders the total count once, then one compact
  Entrate/Uscite/Differenza line per currency, each labeled with its currency.
