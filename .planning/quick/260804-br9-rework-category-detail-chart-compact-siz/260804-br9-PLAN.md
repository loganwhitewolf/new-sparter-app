<objective>
Rework the category detail page's top chart from a 640x220 SVG delta-vs-previous-year chart into a
compact monthly-amounts bar chart (same semantics as the list's `CategorySparkline`), and replace
the `12/9/6/3` + start-month window controls with exactly two views — **YTD** (default: January
through the current month, no projection anywhere) and **Proiezione** (opt-in: all 12 months, pace
projection + current-month hybrid, today's existing behaviour) — that govern the whole detail page:
chart, table rows, subcategory breakdown, and every total/average.

Purpose: fix three real-use problems (CONTEXT.md `<domain>`): the chart is oversized next to the
list's compact sparkline; it plots a delta-vs-previous-year that reads as "empty" for elapsed
months and "identical" for future months whenever the previous year has no history; and a
year-end projection should never be shown by default — it is a deliberate per-category opt-in.

Output: `getCategoryDetailYearWindow` takes a `view` discriminator instead of an arbitrary
month-count window; a rewritten, compact `CategoryDetailAmountsChart`; a new
`CategoryDetailViewToggle` (hidden outside the current year); `parseCategoryDetailWindow` and its
window-controls component deleted with no dead references left.

**Locked decisions (`260804-br9-CONTEXT.md` — do not revisit):**
- **CDET-VIEW-01** Chart becomes a monthly-amounts bar chart (bars = the category's own spend per
  month), reusing the list sparkline's visual semantics. The previous-year delta/comparison stays
  ONLY in the table below — removed entirely from the chart.
- **CDET-VIEW-02** Exactly two views replace the `months`/`from` window: **YTD (default)** —
  January through the current month, no `pace`-filled future months anywhere, current month shows
  the raw actual spent so far (never `computeCurrentMonthHybrid`), total from actual data only.
  **Proiezione (opt-in)** — the current behaviour: all 12 months, future months at `pace`, current
  month hybridized, year-end total.
- **CDET-VIEW-03** The chosen view governs the WHOLE page — table rows, subcategory breakdown,
  every total/average — not just the chart.
- **CDET-VIEW-04** `?months=`/`?from=` and their validation helper are removed entirely; stale deep
  links degrade silently to YTD. `?year=` and `?lens=` (back-link passthrough) are unchanged.
- **CDET-VIEW-05 (resolved discretion)** A past year hides the toggle (not disables it) — both
  views resolve to the identical 12-month series there, so showing a meaningless choice is worse
  than omitting it.

**Other resolved discretion points (CONTEXT.md `## Claude's Discretion`):**
- URL param: single `?view=ytd|projection`, `ytd` absent/default — mirrors this page's existing
  `?year=`/`?lens=` implicit-default convention.
- Toggle shape: a 2-pill button group (`role="group"`), visually consistent with the deleted
  window-controls' own pill group.
- Chart geometry: no fixed SVG canvas at all — rewritten as CSS flex/div bars (see Task 2), which
  are intrinsically responsive (no `min-w-[520px]`/`overflow-x-auto` needed).
- Reuse over reimplementation: the chart imports the sparkline's own `resolveBarFillStyle` rather
  than re-deriving per-state fill logic. `classifyMonthStates` is NOT re-called by the chart — the
  DAL already attaches a resolved `.state` to every month.
- `category-detail-difference-chart.tsx` is rewritten IN PLACE (same file/test path — the
  constraint that this test file be "updated, not deleted" requires it), with its exported symbol
  renamed to `CategoryDetailAmountsChart` since it no longer renders a difference/delta.
</objective>
