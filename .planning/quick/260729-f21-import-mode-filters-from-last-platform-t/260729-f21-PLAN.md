<objective>
Add three import mode filters on the analyze/preview step: from last platform transaction (default), all transactions, and date range — with live filtered preview and a "Transazioni nel periodo" summary card.

Purpose: bank files often re-include already-imported days that hash dedup misses (format drift / alternate feeds). Date-based mode filtering lets the user import only the intended window while keeping hash dedup as defense in depth (D-03).

Output: shared filter util + DAL last-date query + analyze/confirm wiring + ImportPreview UI (filters beside title, period card, live refresh).
</objective>
