# Quick Task 260729-f21: Import mode filters - Context

**Gathered:** 2026-07-29
**Status:** Ready for planning

<domain>
## Task Boundary

Improve the import process with three mode filters next to the title:

1. **From last platform transaction** (default) — import only transactions after the last imported transaction for that platform. Example: last imported on July 14 → import from July 15 onward.
2. **All transactions** — current behavior (full file).
3. **Date range** — user picks a manual date interval.

Default order: 1 → 2 → 3. Filter 1 is the default selection.

**Preview:** every filter change refreshes the import preview to show only rows matching the active filter.

**New summary card:** "Transazioni nel periodo" — shows start/end dates of the transactions currently selected by the filter (for "all", the full file span; for other modes, the effective filtered span).

Problem being solved: files may contain already-imported transactions that hash-based dedup fails to recognize (CSV format drift, or same platform data arriving from another service with different description hashes).

</domain>

<decisions>
## Implementation Decisions

### Boundary of "from last transaction"
- Use calendar-date cutoff: `transactionDate > lastImportedDate` (entire last day excluded).
- Same-day recovery is intentional UX: user switches to **date range**; range defaults to the selection implied by filter 1 (day after last import → end of file); user can move the start back one day to include the last day itself.

### Empty platform (no prior transactions)
- Filter 1 stays selected as default but behaves like "all" (no cutoff) when the platform has no prior transactions.

### Dedup vs date filter
- Description-hash duplicate detection remains active on the filtered subset (defense in depth).

### Claude's Discretion
- UI control pattern for the three filters (segmented control / tabs / toggle group) — match existing import UI patterns.
- Where to load `lastImportedDate` (DAL query by platform) and how to thread filter params through preview + confirm actions.
- Exact Italian labels for filters and the new card, consistent with existing import copy.
- Range date-picker placement when mode 3 is selected.

</decisions>

<specifics>
## Specific Ideas

- Filters placed at the top, next to the title.
- New card alongside existing ones (rows found, duplicates, platform): "Transazioni nel periodo".
- Live preview refresh on every filter change.
- Range mode pre-filled from filter-1 effective window so the user can nudge start back one day if needed.

</specifics>
