# Wave 01: Contrast + onboarding + Categorizza UI

## Goal

Stepper onboarding leggibile e centrato; area dropzone prominente; contrasto ≥ 4.5:1 sul testo secondario in tre superfici (hint upload, copy education, chip filtro inattivi) più movimento/placeholder nella modale Categorizza.

## Context

Locked in `260731-hhv-CONTEXT.md`. Shared contrast approach for 1.2 / 1.4 / 2.1 — one token/utility, three call sites. Chip labels stay Tutte / Entrate / Uscite / Accantonamenti / Trasferimenti (feedback mockup said "Abbonamenti"; product uses Accantonamenti — do not rename chips).

- `app/(app)/onboarding/_components/step-3-education.tsx` — `Le altre N erano già note…`

- `tests/subcategory-picker.test.tsx` — assert inactive chip class/utility if practical

**Action:**
1. Introduce **one** shared approach for secondary text / inactive chip label contrast ≥ 4.5:1 on both onboarding dark theme and default app surfaces (WCAG AA normal text). Prefer a utility class or CSS variable (e.g. readable secondary on `--background`) over per-call-site opacity hacks like `text-foreground/30`.

3. Apply the same contrast rule to inactive filter chips in `TypeChips` / `Chip` (2.1): inactive labels must remain ≥ 4.5:1 against the sheet background; active chip keeps primary/selected styling.
4. Do not rename chip labels to Abbonamenti. Do not restyle selected chip beyond contrast needs.

**Verify:**

**Done when:** 1.2, 1.4, and 2.1 share one contrast mechanism; inactive chips and the two onboarding secondary strings meet ≥ 4.5:1 intent; no Abbonamenti rename.
