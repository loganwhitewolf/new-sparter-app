<objective>
Confine the cassa/competenza lens switch to Overview (RETIRE-03, D-12) and drop the dead `tag`
parameter from dashboard tab navigation while preserving `?lens=` invisible propagation (RETIRE-04,
D-13, D-14).

Purpose: removing the LensSwitch control alone is not sufficient — the two Categories pages must
also stop resolving `?lens=` into anything but the cash row source, or a crafted URL would silently
change what "always cassa" computes, contradicting ADR 0020 §7's promise.
Output: Categories pages pinned to cash; category-ranking-list.tsx's now-unused lens prop removed;
buildDashboardTabHref's dead `tag` param dropped; a source-level regression test proving the render
site inventory.
</objective>
