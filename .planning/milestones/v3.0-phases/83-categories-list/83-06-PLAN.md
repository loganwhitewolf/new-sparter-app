year the row's own total was computed from, so the row's total and the detail page's total agree.
This plan does not touch D-09's reachability (the direction filter keeps offering Accantonamenti)
— it scopes D-13's link-coherence guarantee to the two directions (`in`/`out`) whose detail page
already honours it, and makes the third direction's row provably inert instead of silently broken.

the detail page's total agree") currently fails for `allocation` rows — a user clicking a €500
Accantonamenti row lands on a €0 detail page with a back link that silently returns them to the
Uscite list. Making the allocation row non-interactive removes the broken path entirely, at the
explicitly accepted cost that Accantonamenti detail-drilldown stays unavailable until Phase 84
rewrites that page.
Output: `components/dashboard/category-ranking-list.tsx` renders a non-interactive,
`aria-disabled="true"` name element for `allocation`-direction rows instead of a `<Link>`; `out`
and `in` rows are unaffected.
