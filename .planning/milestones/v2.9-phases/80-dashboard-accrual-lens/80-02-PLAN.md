<objective>
Migrate the remaining five aggregation functions in `lib/dal/dashboard.ts` (getCategoriesBreakdown,
getCategoryRanking, getCategoryDeviations, getCategoryDetail, getMonthlyTrendByNature) to accept
the `ledgerRowSource` parameter established by the Plan 80-01 tracer, following the exact same
swap-the-FROM-clause pattern proven there. `getCategoryDetail`'s third sub-query (topTransactionRows)
needs a real redesign, not a mechanical swap: today it reads `FROM transaction` and joins
`ledgerEntryCash` only to filter/order, displaying the RAW un-netted `transaction.amount` — an
amortization instalment has no corresponding `transaction` row, so this sub-query must instead read
`FROM ledgerRowSource` and LEFT JOIN `transaction` back in for display-only context (description,
customTitle), falling back to the shared Standalone Expense's title when no transaction row exists.

Purpose: extend the proven seam-threading pattern across dashboard.ts's category-facing widgets
(LENS-02: category breakdown, ranking, deviations, monthly trend, Top 5 movimenti).
Output: all six dashboard.ts aggregation functions (five here + getOverviewAmountTotals from 80-01)
are lens-selectable; cash stays byte-identical.
</objective>
