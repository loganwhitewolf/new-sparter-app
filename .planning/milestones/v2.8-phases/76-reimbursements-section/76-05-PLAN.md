## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Browser -> /reimbursements/[id] route param | untrusted `id` string crosses into `getReimbursement`'s ownership+anchor-shape guard |
| Browser -> updateReimbursementTitleAction FormData | untrusted `reimbursementId`/`title` cross into an UPDATE statement |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-76-01 | Tampering / Information Disclosure | app/(app)/reimbursements/[id]/page.tsx | high | mitigate | `getReimbursement(userId, reimbursementId)` scopes on BOTH `reimbursement.userId = userId` AND `expenseId IS NOT NULL` in one WHERE clause; a foreign-owned OR Group-anchored id resolves identically to `undefined` -> `notFound()` — no distinguishing signal (mirrors `/tags/[id]`'s guard). |
