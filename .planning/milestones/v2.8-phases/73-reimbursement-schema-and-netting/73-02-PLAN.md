<objective>
Expand Plan 73-01's narrow N=1 tracer proof into the full regression matrix ADR 0018 and the
spec-less probe fallback require, and add the D-02 invariant enforcement (outflow-anchor /
inflow-refund) that Plan 73-01 deferred. This plan does not touch any new production consumer code
— lib/dal/dashboard.ts, overview.ts, tags.ts already pick up 73-01's generalized
effectiveAmount()/isNotSecondary() with zero changes (per 73-PATTERNS.md: "no changes to query
shape needed at these call sites").

73-CONTEXT.md (dinner N>1, adjacency at and past the anchor's magnitude, refund-order determinism,
the Q3 multi-transaction-Expense edge) — not just the N=1 case — across every one of the 10
verified aggregation functions (not only effectiveAmount() in isolation or the 2 functions the
original research inventory named), and give D-02 a concrete, testable, reusable enforcement point
before Plan 73-04 wires it into the live write path.
Output: `lib/services/reimbursement-invariant.ts`, an expanded regression suite covering 5 real
scenarios each asserted across the full 10-function aggregation surface (reusing 73-01's
`captureAggregationSnapshot` helper), and a dedicated migration-backfill correctness suite
(row-count reconciliation, zero orphans, zero-row safety).
